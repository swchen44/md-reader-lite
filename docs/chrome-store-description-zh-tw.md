## 詳細描述（Description，上限約 16000 字元）

**隱私優先的 Markdown 閱讀器。**

MD Reader Lite 在瀏覽器本機渲染 Markdown，預設開啟「離線模式」，沒有分析或追蹤後端。Mermaid、ZenUML、Graphviz 與數學公式使用套件內程式，不連 CDN 或渲染伺服器；選用的 PlantUML 則使用你指定的伺服器。

主要特色：

- 🔒 隱私優先：離線模式封鎖自動刷新、GitHub API 目錄、PlantUML 與支援的遠端媒體引用；設定與確認的搜尋詞只存裝置本機
- 📁 檔案導覽：目錄樹瀏覽、GitHub 檔案樹、Obsidian 風格雙向連結
- 🔍 全文搜尋：檔案樹內即時依檔名搜尋，跨檔案切換不遺失搜尋結果
- 🕘 導覽搜尋歷史：按 Enter 記錄搜尋詞，重開可看最近紀錄；方向鍵選取、Tab 補完，預設保留 10 筆，可調整上限或清除
- 🎨 多種主題與自訂字體大小
- Mermaid 12 支援 31 種圖，包含內建 ZenUML；預設 Anthropic blog style，可從選單切回 Original；支援 GitHub raw 沙盒頁面
- 🧩 CSS 客製化：新安裝預設套用 Developer 風格；可選兩個唯讀內建風格或編輯兩個本機 CSS 欄位，按「套用」後才生效
- ⌨️ 快捷鍵支援，操作更快速
- 🖱️ Anthropic 風格設定與浮動導覽；拖曳邊緣調寬並記憶寬度，文章不重新排版；新安裝預設文章寬度 85%
- 🔎 PlantUML 圖表渲染（選用功能，預設關閉，離線模式下自動停用；可自架內網伺服器）

支援本機（file://）與線上（http://、https://）Markdown 檔案，涵蓋常見的 Markdown 副檔名，也可選擇開啟支援純文字 .txt 檔。

線上文件及其媒體仍涉及網路連線，開啟「檔案」頁籤也可能請求目錄列表。離線模式不涵蓋任意文件 CSS 或網頁中的相對媒體網址。只有同時開啟 PlantUML 並關閉離線模式時，才會將圖表原碼送往指定伺服器；完整行為及限制見隱私權政策。

源自開源 md-reader（MIT）並加入新功能，為獨立商店項目。
