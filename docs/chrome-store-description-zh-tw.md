## 詳細描述（Description，上限約 16000 字元）

**隱私優先的 Markdown 閱讀器。**

MD Reader Lite 預設開啟「離線模式」，安裝後零網路連線、零追蹤——所有 Markdown 渲染都在你的瀏覽器本機完成，不會把你的檔案內容送到任何第三方伺服器。

主要特色：

- 🔒 隱私優先：離線模式總開關，預設封鎖所有對外連線（可稽核、可實測）
- 📁 檔案導覽：目錄樹瀏覽、GitHub 檔案樹、Obsidian 風格雙向連結
- 🔍 全文搜尋：檔案樹內即時依檔名搜尋，跨檔案切換不遺失搜尋結果
- 🎨 多種主題與自訂字體大小
- ⌨️ 快捷鍵支援，操作更快速
- 🖱️ 浮動選單、可調整寬度側邊欄
- 🔎 PlantUML 圖表渲染（選用功能，預設關閉，離線模式下自動停用；可自架內網伺服器）

支援本機（file://）與線上（http://、https://）Markdown 檔案，副檔名涵蓋 .md、.markdown、.mkd、.mdx、.mdc（.txt 選用開啟）。

適合工程師、寫作者、筆記使用者：不需要把檔案上傳雲端，也不用擔心閱讀紀錄外洩。
