## Description (up to ~16,000 characters)

**A privacy-first Markdown reader.**

MD Reader Lite renders Markdown locally, with Offline Mode on by default and no analytics or tracking backend. Mermaid, ZenUML, Graphviz and math rendering use bundled code, without a CDN or rendering server. Optional PlantUML rendering uses a server you choose.

Key features:

- 🔒 Privacy-first: Offline Mode blocks auto-refresh, GitHub API browsing, PlantUML and supported remote media references; settings and confirmed search terms stay on your device
- 📁 File navigation: folder tree browsing, GitHub file tree, Obsidian-style backlinks
- 🔍 Full-text search: instant filename search in the file tree, search results persist across file switches
- 🕘 Navigation search history: press Enter to record a query; reopen to see recent terms, use arrow keys and Tab to complete; keep 10 by default, adjust the limit or clear history
- 🎨 Multiple themes and adjustable font size
- Mermaid 12 with 31 diagram types, including bundled ZenUML; Anthropic blog style by default, with Original available from the style menu; GitHub raw sandbox pages supported
- 🧩 CSS customization: Developer style is active by default on new installs; select two built-in read-only presets or edit either of two local CSS slots, then Apply
- ⌨️ Keyboard shortcuts for faster navigation
- 🖱️ Anthropic-style settings and floating navigation; drag the sidebar edge to resize, remember its width, and keep the article layout fixed; new installs use 85% article width
- 🔎 PlantUML diagram rendering (opt-in, off by default, automatically disabled under Offline Mode; self-hostable on your own intranet)

Works with local (file://) and online (http://, https://) Markdown files, including several common Markdown file extensions and, if you opt in, plain .txt files.

Online documents and their media still involve network access. Opening the Files tab can request a directory listing. Offline Mode does not cover arbitrary document CSS or relative media URLs on web pages. PlantUML sends diagram source to the configured server only when enabled with Offline Mode off. See the linked privacy policy for the complete behavior and limitations.

Forked from the open-source md-reader (MIT), with additional features. This is a separate store listing.
