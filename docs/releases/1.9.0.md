# MD Reader Lite 1.9.0

## 變更

- 升級 Mermaid 12.2.0，內建 ZenUML，支援 31 種圖與 Original／Anthropic 兩種風格。
- Mermaid、設定面板與左側導覽使用 Anthropic 編輯風格；新安裝預設 85% 文章寬度。
- 左側浮動欄不推擠文章，可拖曳調整寬度並記憶。
- GitHub raw 沙盒頁面使用插件私有 offscreen 文件繪圖，沿用本機 renderer 與資源防護。
- 搜尋歷史支援主鍵盤／數字鍵盤 Enter、候選補完、空白重開最近紀錄、跨頁合併／清除同步與選取保留。
- ZIP 納入完整 third-party notices；移除過時 `version_name: 1.0.4`，以正式 version 顯示 1.9.0。
- 更新商店雙語文案與既有項目上傳教學；明確揭露文件相對媒體／CSS 的既有離線防護限制，與本機 Mermaid renderer 分開判斷。

## 權限與資料邊界

相較 1.8.2 新增 `offscreen`，僅供本機 DOM／SVG 處理；不新增 host permission，不使用 Mermaid CDN 或渲染伺服器。搜尋詞與設定只存本機。文件媒體、使用者 opt-in 功能及 PlantUML 的既有網路邊界見 [PRIVACY.md](../../PRIVACY.md)。
