# MD Reader Lite 1.9.0

## 變更

- 升級 Mermaid 12.2.0，內建 ZenUML，支援 31 種圖與 Original／Anthropic 兩種風格。
- Mermaid、設定面板與左側導覽使用 Anthropic 編輯風格；新安裝預設 85% 文章寬度。
- 左側浮動欄不推擠文章，可拖曳調整寬度並記憶。
- GitHub raw 沙盒頁面使用插件私有 offscreen 文件繪圖，沿用本機 renderer 與資源防護。
- 搜尋歷史支援主鍵盤／數字鍵盤 Enter、候選補完、空白重開最近紀錄、跨頁合併／清除同步與選取保留。
- ZIP 納入完整 third-party notices；移除過時 `version_name: 1.0.4`，以正式 version 顯示 1.9.0。
- 更新商店雙語文案與既有項目上傳教學；明確揭露文件相對媒體／CSS 的既有離線防護限制，與本機 Mermaid renderer 分開判斷。

## 權限與資料邊界

相較 1.8.2 新增 `offscreen`，僅供本機 DOM／SVG 處理；不新增 host permission，不使用 Mermaid CDN 或渲染伺服器。搜尋詞與設定只存本機。文件媒體、使用者 opt-in 功能及 PlantUML 的既有網路邊界見 [PRIVACY.md](../../PRIVACY.md)。

## 永久重測方式

依 [Developer Guide](../developer_guide.md#發佈release) 完成格式、unit、typecheck、build 與完整 serial headed e2e。缺少瀏覽器造成的 skip 不算通過；先建置再跑 e2e，一次只執行一套 headed suite。此版本的驗收基準為 296 unit／194 e2e，未來新增測試時允許筆數增加，仍須核對零 fail／cancel／skip／TODO。

發布成品另核對：ZIP integrity；根目錄 manifest version 與 package／tag 一致；沒有過時 version_name、私鑰或原始碼目錄；`offscreen` 權限及 renderer／offscreen HTML、JS 和完整 notices 存在；private offscreen 檔未列入 web-accessible resources。下載 GitHub asset 後驗證其 SHA-256 與 API digest 一致。不同平台建置的壓縮時間可能不同，不以本機 ZIP 與 CI ZIP 的位元組相同作為必要條件。

重測正式附件時，先保留現有 `extension/`，將下載的 ZIP 解壓到 repo 的 `extension/`，逐檔核對與 ZIP 相同，再執行 `npm run test:e2e`。**解壓正式附件後不要再次 build**，否則會改測本機重建版本。將所測附件 SHA-256、Chrome 版本、exit code、完整筆數及 skip 記入 receipt。
